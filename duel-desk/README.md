# 듀얼 상담소 (claude.ai 페이지 버전)

claude.ai에 게시한 유희왕 상담 챗봇 페이지의 원본입니다. 오랜 찐친 나나세가 반말로 편하게 룰 판정, 카드 효과 해석, 덱 고민을 같이 봐 줍니다.

- 게시 주소: https://claude.ai/artifact/EmLAy2GsK6pDTAfCePinbD
- API 키가 필요 없습니다. 답변은 페이지를 연 사람의 Claude 계정으로 생성됩니다.
- 이 페이지는 claude.ai의 Artifact 기능(`window.claude.use("sample")`)으로 Claude를 호출하므로, 파일을 브라우저에서 직접 열면 Claude에 연결되지 않습니다. 수정한 뒤에는 claude.ai에 다시 게시해야 반영됩니다.
- `index.html`에는 `<html>`, `<head>` 태그가 없습니다. 게시할 때 claude.ai가 자동으로 감싸 줍니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 본문 (화면, 스타일, 챗봇 지침, 동작 스크립트) |
| `nanase-face.webp` | 기본 얼굴 (`images/nanase.png`에서 잘라 줄인 것) |
| `nanase_smile-face.webp` | 미소 얼굴 (`images/nanase_smile.png`에서 잘라 줄인 것) |
| `nanase-full.webp` | 프로필 카드의 전신 이미지 |
| `cards.json` | 카드 데이터 (YGOPRODeck, 14,540장, 2026-11-11 기준, 영어 TCG 텍스트) |
| `build_cards.py` | `cards.json`을 새로 받아 만드는 스크립트 |

## 채팅 동작

- 메신저 앱처럼 나나세의 답장이 짧은 말풍선 여러 개로 나뉘어 옵니다. Claude가 빈 줄로 구분해 보낸 덩어리 하나가 말풍선 하나가 됩니다.
- 글머리표, 굵게 같은 마크다운은 쓰지 않도록 지침에 넣었고, 혹시 섞여 와도 화면에서는 기호를 지우고 보여 줍니다.
- 보낸 메시지 옆의 숫자 1은 나나세가 읽으면 사라지고, 답장을 쓰는 동안 입력 중 표시가 나옵니다.
- 머리글의 나나세 이름이나 얼굴을 누르면 프로필(전신 이미지)이 열립니다. 답변 방식과 대화 지우기는 오른쪽 위 메뉴에 있습니다.

## 카드 검색

claude.ai 페이지는 외부 사이트를 직접 호출할 수 없어서, 카드 데이터를 미리 받아 `cards.json`으로 페이지와 함께 게시합니다.

1. 메시지를 보내면 Claude(빠른 모델)가 어떤 카드나 테마 얘기인지 공식 영어 이름으로 뽑습니다. 한국어 이름이나 별명(예: 블매, 하루우라라)도 영어 이름으로 바꿉니다.
2. 페이지가 `cards.json`에서 그 카드를 찾고, 대화 화면에 "카드 DB 확인: …"으로 표시합니다.
3. 찾은 공식 텍스트를 붙여서 나나세가 답합니다. 나나세는 기억보다 이 텍스트를 우선합니다.

데이터에는 한국어 카드명이 없어서 이름 변환은 Claude의 지식에 의존합니다. 최신 카드나 잘 알려지지 않은 카드는 영어 이름으로 물어보면 더 정확합니다.

데이터 갱신: `python duel-desk/build_cards.py`를 실행한 뒤 `index.html`의 `DB_DATE`와 메뉴 안내문 날짜를 바꾸고 다시 게시합니다.

## 미소 표정 동작

챗봇 지침(`index.html`의 `RULES`)에 따라 Claude가 웃는 표정이 어울리는 답변 끝에 `[[미소]]` 표시를 남기면, 화면에서는 표시를 숨기고 얼굴 이미지를 미소 모습으로 바꿉니다. 웃는 조건을 바꾸려면 `RULES`의 "표정 표시" 문단을 수정하세요.
